My Story                                

Ritesh Yadav

Creator & Lead Developer

I am Ritesh Yadav, the creator and lead developer of HelloDoc. What started as a simple idea to make healthcare accessible from home grew into a full-featured web application with doctor search, appointment booking, symptom prediction, and user authentication. I designed the entire user interface from scratch, creating a clean and intuitive experience that works across devices. The platform features a modern navbar system, responsive layouts, interactive doctor cards, a booking modal, and a comprehensive help center. I also implemented the login and signup flows with form validation and session management. For the frontend, I used HTML5, CSS3, JavaScript (ES6+), the Inter font family, Font Awesome icons, and responsive design principles. I chose vanilla web technologies for fast loading and broad compatibility.

Technology I Used

Frontend (what I built)

  • HTML5 - Semantic markup and structure
  • CSS3 - Custom properties, flexbox, grid, animations
  • JavaScript (ES6+) - DOM manipulation, fetch API, modules
  • Inter - Modern sans-serif typeface
  • Font Awesome 6 - Icon library

Backend (what I set up)

  • Node.js - JavaScript runtime
  • Express.js - Web framework
  • MySQL - Database for users and appointments
  • bcryptjs - Password hashing
  • JSON Web Tokens - Session authentication

AI/ML (what I integrated)

  • Python - Machine learning runtime
  • Scikit-learn - Disease prediction models
  • NumPy, Pandas - Data processing
  • Flask - ML API serving

Infrastructure (what I deployed to)

  • Vercel - Frontend hosting and deployment
  • Cloudflare Workers - Edge runtime (preview)
  • Swagger/OpenAPI - API documentation
